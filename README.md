# Final Exam Prep · Professional English

Interactive practice site for the **Vocabulary** and **Grammar** sections of the Professional English final exam (Weeks 1–9).

- **4 exam-format tests**: 10 vocabulary + 10 grammar multiple-choice questions each (2 points per question, 40 points max). Questions and answer options are drawn at random from each test's pool every time.
- **197 questions** in total (94 vocabulary + 103 grammar), each with an explanation in Russian.
- Extra modes: **Weeks 6–9** focus, **Marathon** (all questions), and **Mistakes review** (questions you got wrong, saved in your browser).
- **Glossary**: 293 words and phrases with English definitions and Russian translations, plus search and week filters.
- **Grammar**: rules, formulas, examples and typical mistakes for every topic.

## Run locally
Open `index.html` in any browser. It's a single file with no dependencies.

## Publish on GitHub Pages
1. Create a new repository and upload `index.html` (and this README).
2. Go to **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. After about a minute, the site will be live at `https://<your-username>.github.io/<repo-name>/`.
